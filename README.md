# vortex-303/homebrew-tap

```sh
brew install vortex-303/tap/capturist                 # capturist CLI + local MCP server (MIT)
brew trust vortex-303/tap                             # Homebrew asks you to trust a tap once before its casks
brew install --cask vortex-303/tap/capturist-complete # Capturist Complete, free public beta
```

- **capturist**: give Claude, ChatGPT and Codex your Mac screenshots. Source: https://github.com/vortex-303/capturist-mcp
- **Capturist Complete**: Mac menu bar screenshot, snippet and clipboard library with on-device text search. https://capturist.nodetools.org

macOS 14 Sonoma or later.
